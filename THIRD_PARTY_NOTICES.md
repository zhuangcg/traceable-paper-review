## Dependencies and names

This repository does not bundle third-party papers, models or library source code.
PyMuPDF is an optional runtime dependency and has its own licensing terms:
https://pymupdf.readthedocs.io/en/latest/about.html
MinerU is an optional upstream conversion tool, not a bundled dependency:
https://github.com/opendatalab/MinerU

Codex, Claude Code and MinerU are names used to explain interoperability.
Their mention does not imply affiliation or endorsement.
